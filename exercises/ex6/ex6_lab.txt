        File name           : code.txt

2. CodeBuild 
    CodeBuild -> Create Project -> name: pipelining_build
    -> Source -> 
        Source provider: AWS CodeCommit 
        Repository : sample_pipelining 
    -> Build commands
        echo "Built Successful"
    -> Create Build Project
    ! You have successfully created the following project: pipelining_build
    <Start Build>
        Build Status: Succeeded
3. CodePipeline 
    Pipelines -> Create Pipeline -> Build custom pipeline
    name: code_and_build
    -> Next -> Source: AWS CodeCommit -> repo: sample_pipelining 
    -> Branch Name : main 
    -> Next 
    -> Build provider : AWS CodeBuild 
    -> Project Name: pipelining_build
    -> Next 
    -> Test Next
    -> Deploy Next 
    Check the summary 
    ==> Create Pipeline 
    ! Congratulations! The pipeline code_and_build has been created.

    Source -> Build
