Lab: DynamoDB CRUD operations
Search DynamoDB -> DynamoDB page is opened 
-> Left Side Menu Bar -> Tables -> Create Table
-> Create table page is opened 
    -> Table name: emps
    -> Partition key: id (string)
       ! The partition key is part of the table's primary key. 
       It is a hash value that is used to retrieve items 
       from your table and allocate data across hosts 
       for scalability and availability.
    -> Click <Create Table> Button 
    ! The emps table was created successfully.
